# 🔐 Cryptography and Cyber Law

A comprehensive academic project focused on **Cryptography and Cyber Law**, covering fundamental cryptographic algorithms, mathematical concepts, network security, authentication, digital signatures, modern encryption techniques, and cybersecurity-related concepts.

This repository contains the project materials, implementations, examples, and academic resources developed as part of the **Cryptography and Cyber Law** coursework.

---

## 📌 Project Overview

**Cryptography and Cyber Law** explores the techniques and principles used to protect information and communication systems from unauthorized access, modification, and attacks.

The project covers important areas including:

* 🔢 Number Theory & Modular Arithmetic
* 🔐 Symmetric-Key Cryptography
* 🔑 Public-Key Cryptography
* ✍️ Digital Signatures
* #️⃣ Cryptographic Hash Functions
* 🌐 Network Security
* 🔒 TLS & IPSec
* 👤 Authentication & Kerberos
* 🧩 Elliptic Curve Cryptography
* ⚛️ Post-Quantum Cryptography
* 📡 IoT Security
* ⚖️ Cyber Law & Security Concepts

### 🔢 Mathematical Foundations

* Fermat's Little Theorem
* Modular Arithmetic
* Extended Euclidean Algorithm

* Finite Fields
* Galois Fields
* Miller–Rabin Primality Testing

### 🔐 Symmetric Cryptography

* Feistel Networks
* AES
* AES Key Expansion
* AES Modes of Operation
* Avalanche Effect
* Playfair Cipher
* Side-Channel Attacks

### 🔑 Asymmetric Cryptography

* RSA
* Diffie–Hellman Key Exchange
* ElGamal
* Elliptic Curve Cryptography (ECC)
* ECDSA
* RSA-CRT Optimization
* Bellcore Fault Attack

### #️⃣ Hashing & Message Authentication

* Cryptographic Hash Functions
* Preimage Resistance
* Second-Preimage Resistance
* Collision Resistance

* HMAC

* SHA-3

### 🌐 Network & Authentication Security

* IPSec
* ESP

* Module-LWE

* IoT Security
